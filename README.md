A simple e-commerce web application built using PHP OOP, MySQL, and PDO.

---

## ⚙️ Tech Stack

- PHP (OOP)
- MySQL
- PDO
- HTML / CSS / JS
- Laragon (Local Server)

---

## 📁 Project Structure

- assets/ → CSS, JS, images
- includes/ → header, footer, db connection
- classes/ → OOP classes
- views/ → frontend pages
- admin/ → admin panel

---

## 🌿 Git Workflow

- main → production (protected)
- develop → development branch
- feature/* → لكل feature branch

Example:
- feature/auth
- feature/products
- feature/cart
- feature/orders

---

## 🚫 Rules

- ممنوع الشغل على main
- أي feature لازم Pull Request
- لازم code review قبل الدمج
